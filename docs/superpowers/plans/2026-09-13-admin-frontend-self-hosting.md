# Admin Frontend Self-Hosting and Verification Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remover dependências remotas do painel e criar validação automatizada do frontend de produção.

**Architecture:** Compilar CSS em estágio Node separado, copiar somente o artefato para a imagem Python e substituir Font Awesome por SVGs locais ou um sprite local. O runtime continuará sem Node e sem chamadas a CDNs.

**Tech Stack:** Docker multi-stage, Node.js LTS no estágio de assets, Tailwind CLI, FastAPI StaticFiles, pytest, Playwright no CI.

**Spec:** `docs/superpowers/specs/2026-09-12-admin-quality-hardening-design.md`

## Global Constraints

- O runtime final permanece baseado em Python 3.11 slim e executa como `appuser`.
- Nenhum recurso remoto é necessário para renderizar ou operar o painel.
- Alpine permanece versionado em `app/admin/static/vendor/alpine.min.js`.
- O build deve ser reproduzível com versões de pacotes fixadas.
